Becuase adding a bot literally named Bdaypheus would be pretty sus, and getting admins perms would be annoying, 
I've come up with the idea of using hc auth to get your user token so it can invite the people from a person's personal private channel!

Take users through the hc auth and make it so that only people who should be able to can!
